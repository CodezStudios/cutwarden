cutwarden

Brand-safe video editing for AI agents, over MCP. The AI edits. It never generates pixels.

View on GitHub Install
  • Edited, not generated. Footage is never altered by a model.
  • Safety in the tools. Only brand color names and font roles are accepted. Safe zones, contrast and reading speed are checked.
  • The AI can see. It renders frames and contact sheets, reviews them and fixes problems.
  • Deterministic. Same project and time give the same pixels.

Connect it

pip install -e .
claude mcp add cutwarden -e CUTWARDEN_BRAND=/path/to/brand.json -- cutwarden-mcp

Hosted endpoint: https://<your-worker>.workers.dev/mcp (token required). Needs Python 3.10+ and FFmpeg to self-host. For ChatGPT, Gemini or other remote clients, run cutwarden-mcp --http --port 8100 and add the URL as a custom connector.
